# Editable family records

Copy a template before filling it in. For personal records, create `private/` at the repository root and save copies there; that directory is excluded from Git by default. It is not encrypted or automatically backed up. Keep the blank templates reusable.

- [Family profile](family-profile.md): routines, interests, languages, care context, and family priorities.
- [Doctor visit](doctor-note.md): observations, clinician findings, instructions, and follow-up.
- [Growth measurements](growth-log.md): dates, units, measurement source, and clinician interpretation.
- [Developmental observations](milestone-observation.md): concrete examples without scoring.
- [Weekly plan and reflection](weekly-plan.md): a small number of optional activities.
- [Childcare handoff](childcare-handoff.md): sleep, meals, interests, and shared questions.

No forms contain actual medical findings or invented measurements. Nothing is sent to childcare or a clinician automatically.
